# the_taste_of_wondering
边走边吃
 
这不是一本旅行攻略。
这里没有“十大必去景点”，也没有“网红餐厅排行榜”，甚至很多故事发生的地点，都不是那个国家最有名的地方。
这也不是一本美食书。食物只是这些故事的入口。我真正想记录的，是一种生活方式，一种迁移中的观察，以及人与地方之间慢慢建立起来的联系。
二十多年来，我自己和身边的人，因为求学、工作、探亲，在不同国家之间不断迁移。从中国到英国，再到欧洲、亚洲以及世界各地，我渐渐发现，一个地方真正留在记忆里的，往往不是教科书里的历史，也不是明信片上的风景，而是一种味道，是一道菜、一杯茶、一块面包、一条鱼带来的感觉。
旅行结束以后，留在回味里的，往往是一杯在尼泊尔山谷里喝过的奶茶；是香港清晨，烧鹅师傅起刀落刀时升起的白色热气；是巴黎回程火车上一路飘散的马蹄酥黄油香；也是索伦托街角，那张刚刚从老窑炉里出炉的玛格丽特披萨，混着番茄、罗勒和木柴火的味道。
让我怀念的，不只是食物本身，更是食物背后的人。
是在尼泊尔山间茶亭里，认真谈论自己国家未来的年轻人；是在英国康沃尔凌晨结束鱼市交易的渔民；是在越南市场里耐心介绍各种香草的老师；是在巴塞罗那热情切着火腿的小哥。是父亲把从巴黎带回来的香草种子、从意大利带回来的辣椒种子，小心翼翼地种进家里的花盆。正是他们，让一个地方，从地图上的名字，变成了真实存在的生活。
父亲从巴黎带回来的香草、从意大利带回来的辣椒，后来真的在家里的花盆里长了出来。看着它们一点点发芽、开花、结果。有一刻，我忽然觉得，人和植物其实很像。
植物随着人迁移，在另一片土地重新扎根；人也是如此。我们把一个地方的一部分带进自己的生活，一种味道、一粒种子、一段习惯，甚至一句话，都可能在另一个地方慢慢生长。
所以，这本书真正记录的，不只是旅行和美食。
它记录的是人在迁移，食物也在迁移；植物在迁移，文化也在迁移。而人与地方之间，会因为这些看似微不足道的小事，建立起一种温柔而漫长的连接。
在旅行时，和当地人聊几句，去一次市场，留意街角的一家小店；回家以后，把一粒远方带回来的种子种进土里，看看它会不会发芽。这些让我觉得，远方可期，世界值得探索。 
每一次出发，都不会只是一次旅行。我们总会带走一点什么，也总会留下点什么。
而这本书，记录的，就是这些关于迁移、食物与旅行的故事。
